\# CICT Org Fair



\*\*Live Website:\*\* https://apryl9.github.io/org-fair/



\## About

CICT Org Fair is an application that helps students explore CICT organizations and view their upcoming events.



\## Features

\- Browse CICT organizations.

\- View upcoming events.

\- Check event schedules.

\- View organization information.



\## Technologies Used

\- Flutter

\- Dart

\- Contentful CMS

\- GitHub Pages
